# 디자인 시안

Claude Design 캔버스의 보드 파일이에요. `canvas.json`이 캔버스 배치이고, `*.dc.html`이 화면 하나씩이에요.

- 캔버스 밖에서 브라우저로 열면 `support.js`가 없어서, 다른 보드를 불러와 겹쳐 그리는 팝업·메뉴 보드는 바탕 화면이 비어 보여요.
- `/_blob/...` 표지 사진은 캔버스 저장소에만 있어서 여기서는 안 보여요.

## 링크 없이 보기

`export/` 폴더의 PDF로 캔버스 없이 전체 시안을 볼 수 있어요.

- `TripPlanner_시안_화면흐름.pdf`: 화면 흐름 순서대로, 한 쪽에 같은 줄의 화면을 최대 6개씩 담았어요.
- `TripPlanner_시안_디자인토큰_컴포넌트.pdf`: 토큰, 아이콘, 레이아웃, 뱃지, 컴포넌트 보드를 한 쪽에 하나씩 담았어요.
- PDF의 아이콘은 Material Symbols Rounded 원본 SVG로 다시 그린 근사치라서 캔버스와 모양이 조금 다를 수 있어요.
