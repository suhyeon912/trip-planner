여행 플래너 (TripPlanner)

여행 날짜·비행기·숙소·갈 곳을 한곳에 모아 두면, 하루 동선 후보를 여러 개 만들어 비교하고 고를 수 있는 안드로이드 앱입니다.

14주차 발표 Kotlin · XML Views Room · ViewModel 국내 카카오맵 / 해외 구글맵 2026-11-06 기준 정리
1. 프로젝트 소개 2. 기술 스택 3. 구현 기능 현재 상태 · 다음 단계

1프로젝트 소개

여행 준비 중 흩어지는 정보와 "어디부터 갈까?" 고민을 한 앱에서 해결하는 것이 목표입니다.

1

한곳에 모으는 여행 정보

여행 기간, 비행기 일정, 숙소, 갈 곳 후보와 확정된 장소, 하고 싶은 거 메모를 여행별로 관리합니다.

2

장소마다 필요한 정보만

장소 이름을 누르면 카드가 펼쳐지며 운영시간, 브레이크 타임, 휴무일, 예약 필수 여부, 메모, 지도 링크를 보여 줍니다.

3

경로 후보를 여러 개

지도 앱 길찾기처럼 하루 동선을 A·B·C 세 가지로 제안하고, 이동거리·대기 시간·운영시간 충돌을 비교해 고릅니다.

예시 데이터

앱을 처음 실행하면 아래 세 여행이 자동으로 들어가 바로 시연할 수 있습니다. 운영시간·편명 등은 화면 확인용 임의 값입니다.

  • 부산 2박 3일 (국내) — 지도 버튼이 카카오맵으로 열림, 1일차에 돼지국밥집 브레이크 타임 충돌 예시
  • 오사카 3박 4일 (해외) — 1일차에 저녁만 여는 야키니쿠집 대기 시간 예시
  • 타이베이 3박 4일 (해외) — 2일차에 우육면집 브레이크 타임 충돌 예시

3구현된 기능

아래 화면은 실제 앱 코드를 가상 기기(393×852dp)에서 렌더링해 캡처한 것입니다. 이미지를 누르면 크게 볼 수 있어요.

3-1 · 여행 목록

여행을 만들고 관리

첫 화면에서 내 여행을 한눈에 봅니다.

  • + 여행으로 이름·시작일·종료일을 입력해 새 여행 생성 (날짜 형식과 순서 검사)
  • 여행마다 확정·후보 장소 개수 표시
  • 여행을 길게 누르면 수정 또는 삭제. 삭제하면 안의 장소·비행기·숙소도 함께 삭제
3-2 · 여행 상세 · 장소 카드

이름을 누르면 펼쳐지는 장소 카드

상단에 기간·비행기·숙소 요약, 아래에 확정된 갈 곳 / 갈 곳 후보 탭이 있습니다.

  • 확정 장소는 "1일차" 칩으로 표시, 경로를 확정하면 "1일차 · 2"처럼 방문 순서까지
  • 예약이 필요한 곳은 빨간 예약필수 뱃지
  • 펼치면 운영시간, 브레이크 타임, 휴무일, 예약 여부, 머무는 시간, 메모
  • 버튼: 지도 열기 · 메모 · 수정 · 일차 변경 · 후보로/확정으로 · 삭제
3-3 · 후보 → 확정 · 일차 지정

후보에서 확정으로, 며칠째에 갈지까지

아이디어 단계의 장소는 후보 탭에 모아 두고, 가기로 정하면 확정으로 옮깁니다.

  • 확정으로를 누르면 바로 며칠째에 갈지 고르는 창이 뜸 (여행 기간으로 일수 계산)
  • 확정 장소의 일차는 언제든 일차 변경으로 수정
  • 확정에서 후보로 되돌릴 수도 있음
3-4 · 장소 추가 / 수정 · 메모

필요한 정보를 직접 입력

장소 추가와 수정은 같은 화면을 씁니다. 수정할 때는 기존 값이 채워져 있습니다.

  • 이름(필수), 후보/확정, 일차, 운영시간, 브레이크 타임, 휴무일, 예약 필수, 머무는 시간, 메모, 위도·경도
  • 입력 검사: 이름 비었는지, 일차 범위, 위도(-90~90)·경도(-180~180)
  • 위치를 비워 두면 경로 계산에서만 빠지고, 지도는 이름으로 검색
  • 여행 전체의 하고 싶은 거 메모는 상세 화면의 메모 버튼으로
3-5 · 항공 · 숙소

비행기와 숙소 관리

상세 화면의 항공·숙소 버튼으로 들어갑니다.

  • 비행기: 편명, 출발·도착 공항, 출발·도착 시각
  • 숙소: 이름, 체크인·체크아웃, 위도·경도
  • 항목을 누르면 수정 창, 같은 창에서 삭제
  • 숙소 위치는 경로의 출발·도착점으로 쓰이고, 그날 묵는 숙소를 날짜로 골라 씀
3-6 · 경로 제안

하루 동선 후보 A · B · C 비교

일차 탭을 고르면 그날 확정 장소로 경로 후보를 만듭니다. 숙소 10:00 출발 → 장소들 → 숙소 복귀 기준입니다.

A최단 경로

총 이동거리가 가장 짧은 순서

B시간 맞춤

휴무·운영시간 밖·브레이크 타임을 피하고 대기 시간이 적은 순서

C후보 포함

A 경로에서 3km 이내로 들를 수 있는 후보를 최대 2곳 추가

  • 카드마다 총 거리 · 이동 시간 · 대기 시간 · 끝나는 시각과 시간표
  • 충돌은 ⚠ 경고로, 문 열 때까지 기다리면 ⏳ 대기로 표시
  • 이 경로로 확정을 누르면 방문 순서 저장, C안이면 추가된 후보도 확정으로
  • 지도 길찾기로 같은 순서를 지도 앱에서 열기
부산 1일차: A는 돼지국밥집 브레이크 타임(11:30~14:00)에 도착하고, B는 순서를 바꿔 피합니다. 오사카 1일차: A는 저녁만 여는 가게 앞에서 4시간 28분을 기다리지만 B는 2시간 52분으로 줄입니다.
거리·시간은 길찾기 API 없이 직선거리 × 1.3, 평균 시속 15km로 추정한 값입니다. 장소 8곳까지는 모든 순서를 비교하고, 그보다 많으면 가까운 곳부터 잇고 교차를 푸는 방식으로 계산합니다.
3-7 · 국내 / 해외 지도 자동 전환

국내는 카카오맵, 해외는 구글맵

한국에서는 구글맵 길찾기가 제한적이라, 장소 좌표를 보고 지도 앱을 자동으로 고릅니다.

  • 좌표가 대한민국 안이면 카카오맵, 밖이면 구글맵. 버튼 이름도 자동으로 바뀜
  • 제주·울릉도·독도·백령도는 국내, 후쿠오카·쓰시마·북한은 해외로 판별 (대략적인 다각형 영역)
  • 위치가 없는 장소는 같은 여행의 다른 장소·숙소 위치로 짐작
  • 국내 길찾기는 이동수단 선택: 자동차·도보는 전체 경로(경유지 최대 5곳), 대중교통은 경유지가 안 돼서 구간을 하나씩
  • 카카오맵 앱이 없으면 모바일 웹으로 열림. API 키·결제 등록 불필요
3-8 · 저장 · 검증

앱을 꺼도 남는 데이터, 테스트로 확인한 경로 계산

  • Room 저장: 여행·비행기·숙소·장소를 기기 DB에 저장. 앱을 껐다 켜도, 화면을 돌려도 그대로
  • 자동 갱신: 어느 화면에서 바꾸든 LiveData로 다른 화면에 바로 반영
  • 단위 테스트 10개: 최단 경로가 정말 최단인지(모든 순서와 비교), B안이 브레이크 타임을 피하는지, C안이 가까운 후보만 넣는지, 국내/해외 판별(서울·제주·독도 vs 후쿠오카·쓰시마·평양 등)
