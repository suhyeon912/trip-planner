1현재 프로젝트와 UI 구성 요약

사용자 폴더의 코드를 직접 읽었고(작업 사본과 해시 일치 확인), 화면은 Robolectric으로 실제 레이아웃·코드를 가상 기기에서 렌더링해 확인했습니다. 실제 폰·에뮬레이터 실행은 하지 못했습니다(작업 환경에 가상화 지원 없음). 애니메이션·실기기 글꼴·터치감은 코드 기반 판단입니다.

주요 사용자 흐름

① 여행 만들고 정보 채우기

목록 → + 여행(다이얼로그) → 상세 → 항공·숙소 화면 → 비행기/숙소 다이얼로그. 상세로 돌아오면 요약 텍스트 갱신.

② 장소 모으고 확정하기

상세 → + 장소 추가(새 화면, 위도·경도 직접 입력) → 후보 탭 → 카드 펼침 → 확정으로 → 일차 선택 다이얼로그.

③ 하루 동선 고르기

상세 → 경로 제안 → 일차 탭 → A/B/C 카드를 세로로 스크롤하며 비교 → 이 경로로 확정 → 상세에서 "1일차 · 2" 순서 표시.

④ 여행 중 지도 열기

상세 → 카드 펼침 → 카카오맵/구글맵, 또는 경로 화면 → 지도 길찾기 → (국내) 이동수단 선택.

기존 대화와 실제 코드의 차이

대화에서 나온 내용실제 코드
처음 기획안: 동행자 초대·실시간 동기화·후보 투표·AI 경로없음. 이번 개선안에서 이 기능들을 전제로 화면을 설계하지 않았습니다(선택 제안으로만 분리).
지난 정리 문서: "화면 회전에도 데이터 유지"데이터는 유지되지만(ViewModel), 가로 레이아웃 자체는 쓰기 어려운 상태(위 캡처). 데이터 유지와 화면 사용성은 별개.
"여행 수정·삭제 가능"가능하지만 진입 경로가 길게 누르기 하나뿐(TripAdapter.kt), 상세 화면에는 여행 수정 진입점이 없음.
"하고 싶은 거 메모"저장·수정은 되지만 상세 화면 어디에도 내용이 표시되지 않음(버튼 → 다이얼로그에서만 보임).
"확정 장소에 방문 순서 표시"경로를 확정한 날만 순서 숫자가 붙음(orderInDay). 확정 전에는 일차만 보이고 순서는 등록 순.

기존 기능 회귀 확인

  • 처음 실행 시 예시 여행 3개 생성, 시작일 순 정렬
  • 여행 추가·수정·삭제 (⋮와 길게 누르기 모두), 삭제 시 하위 데이터 함께 삭제
  • 상세: 비행기·숙소·메모가 요약 행에 반영, 행 탭으로 기존 화면·다이얼로그 열림
  • 일정/후보 탭 전환, 일차 칩 선택이 회전 후에도 유지
  • 카드 펼침/접힘, 펼침 상태가 목록 갱신 후에도 유지
  • 지도 버튼: 부산 = 카카오맵, 오사카·타이베이 = 구글맵 / 위치 없는 장소는 이름 검색
  • 장소 메모 수정, 장소 수정 화면에 기존 값·확정 상태 표시(지난번 수정한 버그 재발 없음)
  • 후보 → 확정(일차 선택), 일차 변경, 후보로 되돌리기, 삭제 확인창
  • 항공·숙소 추가·수정·삭제
  • 경로: 일차별 A/B/(C) 계산 결과가 현재와 같은 값 (부산 1일차 A 22.3km·경고 1, B 경고 없음 / 오사카 1일차 C 포함)
  • 경로 확정 → 상세에서 순서 숫자 표시, C안이면 후보가 그날 확정으로
  • 국내 길찾기 이동수단 선택(자동차·도보 전체, 대중교통 구간 선택)
  • 상세의 "n일차 경로 제안 보기"가 그 일차 탭으로 열림
  • 툴바 뒤로 / 시스템 뒤로 모두 같은 화면으로 돌아감
  • ./gradlew testDebugUnitTest 10개 통과

UI·접근성·반응형 확인

  • 보라색(#FEF7FF, #E8DEF8)이 어디에도 남지 않음
  • 작은 글자 대비 4.5:1 이상, 12sp 미만 글자 없음
  • 글자 크기 130%·200%에서 버튼·칩 글자 잘림/어색한 줄바꿈 없음
  • 가로 화면에서 장소 카드 3개 이상 보임
  • 태블릿 폭(600dp·840dp)에서 본문 최대 폭·2단 배치
  • TalkBack: 아이콘 버튼 이름, 일차 칩 "n일차, 날짜, 장소 n곳, 선택됨", 카드 펼침 상태 안내, 이모지 중복 낭독 없음
  • 모든 탭 대상 48dp 이상 (레이아웃 검사기 또는 Accessibility Scanner)
  • 키보드/스위치 접근: 포커스 순서가 위→아래, 포커스 표시 보임
  • 빈 상태 4곳(목록·일정·후보·경로)·항공숙소 빈 섹션에 행동 버튼
  • 긴 여행·장소 이름, 긴 메모에서 레이아웃 깨짐 없음
  • 입력 오류가 해당 칸에 표시되고 첫 오류 칸으로 포커스 이동
  • "애니메이션 제거" 설정 시 펼침 전환 애니메이션 생략
  • 에뮬레이터/실기기에서 최종 확인 (이번 분석은 가상 렌더링 기준)
